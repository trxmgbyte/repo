⚙️ Electrum-Qtum Wallet
=======================

Electrum-Qtum is a lightweight and secure wallet designed for managing your **Qtum** assets efficiently. Leveraging the trusted Electrum platform, it offers fast synchronization and support for hardware wallets.

* * *

### Features

* Quick startup without full blockchain download
    
* Support for cold storage and hardware wallets
    
* Compatible with Windows
    
* Open-source and community-driven
